# Binary & Bitwise Visualizer

An interactive tool for visualizing 32-bit binary representations and Javascript bitwise operations such as NOT (~), AND (&), OR (|), left shift (<<), right shift (>>), and unsigned right shift (>>>)

Binary and bitwise operation visualizer. Explore NOT, AND, OR, XOR, shifts, masks and two's complement
